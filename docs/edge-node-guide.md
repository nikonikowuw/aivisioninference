# 边缘节点管理员指南

## 概述

边缘节点管理功能允许您将 C++ 推理引擎注册为平台可管理的节点，实现节点注册、状态监控、算法包远程下发等操作。

---

## 快速入门

### 1. 创建节点

登录管理后台，进入 **设备管理 → 边缘节点** 页面，点击 **添加节点** 按钮。

填写以下信息：

| 字段       | 说明                                          |
|------------|-----------------------------------------------|
| 节点名称   | 唯一标识节点的名称，如 `edge-node-01`          |
| 描述       | 可选，说明节点用途或位置                       |
| HTTP 地址  | 引擎 HTTP 服务地址，如 `http://192.168.1.100:8080` |
| IPC 地址   | (已弃用，可不填，仅做兼容保留)                  |
| 最大负载   | 节点能同时运行的最大推理任务数                 |
| 备注       | 可选，补充信息                                |

### 2. 复制 Token

创建成功后，页面会显示引擎 JWT **Token**。请立即复制并保存到安全位置（Token 仅在创建时显示一次）。

### 3. 配置引擎

在引擎所在设备上，编辑 `engine/.env` 文件（或 `/etc/aivision/engine.env`），填入以下配置：

```ini
# 必须配置
NIKO_ENGINE_PLATFORM_URL=http://your-platform-server:8080
NIKO_ENGINE_NODE_ID=<上一步获取的节点 ID>
NIKO_ENGINE_AUTH_TOKEN=<上一步获取的 Token>

# 可选配置（默认值通常可用）
NIKO_ENGINE_HTTP_PORT=8080
NIKO_ENGINE_MINIO_ENDPOINT=http://minio:9000

# 基础配置
NIKO_ENGINE_HAL_PLATFORM=macos   # 根据实际硬件平台修改
```

### 4. 启动引擎

```bash
cd engine
make dev
```

或直接运行已编译的二进制文件：

```bash
./build/aivision-engine
```

### 5. 验证连接

启动后约 5 秒，平台节点列表页的节点状态应变为 **online**。

```bash
# 在引擎端验证健康检查
curl http://localhost:8080/health
```

预期响应：

```json
{"status":"ok","uptime":5,"current_load":0,"engine_version":"1.0.0"}
```

## 管理节点

### 查看节点列表

在 **设备管理 → 边缘节点** 页面，可以通过以下方式筛选节点：

- **状态筛选**：全部、在线、离线、异常、已禁用
- **关键词搜索**：名称、描述、端点、平台

列表每 10 秒自动刷新，节点状态变更通过 WebSocket 实时同步。

### 查看节点详情

点击节点名称进入详情页，可查看：

- **基本信息**：名称、状态、HTTP 端点、当前负载
- **硬件信息**：CPU 型号、GPU 型号、内存、运行平台
- **运行统计**：运行时长、引擎版本
- **已安装算法**：列出所有已安装算法及安装状态

### 编辑节点

在详情页点击 **编辑** 按钮，可修改节点名称、描述、端点、最大负载、启用状态等配置。

### 状态说明

| 状态     | 说明                                                     |
|----------|----------------------------------------------------------|
| online   | 节点正常运行，每 5 秒心跳                                |
| offline  | 心跳超时（>15 秒无心跳），节点可能已停止                  |
| error    | 引擎报告错误状态                                         |
| disabled | 管理员手动禁用，该节点不会出现在任务推荐列表中             |

## 算法包下发

### 简单下发

1. 进入节点详情页
2. 点击 **下发算法包** 按钮
3. 在对话框中选择要下发的算法包
4. 确认下发

系统将算法包信息放入待下发队列，引擎在下次心跳时获取下载 URL 并开始安装。

### 自动重试

如果算法包安装失败，系统会自动重试（最多 3 次）：

| 重试次数 | 延迟时间 |
|----------|----------|
| 第 1 次   | 5 分钟   |
| 第 2 次   | 10 分钟  |
| 第 3 次   | 20 分钟  |

前台会显示下次重试时间；3 次均失败后请检查引擎日志。

## 任务与节点

### 创建任务时推荐节点

创建 AI 视觉推理任务时：

1. 选择推理算法
2. 系统自动查询已安装该算法且在线、负载最低的节点，标记绿色 **推荐** 标签
3. 管理员可根据实际情况选择其他节点

### 节点离线对任务的影响

- 引擎停止后，平台在 15 秒内检测到心跳超时
- 该节点上运行的所有推理任务状态变更为 **suspended**（已暂停）
- 引擎恢复后，任务自动恢复为 **running**（运行中）

## 常见问题

### 节点一直显示 offline

1. 检查引擎日志（`./build/aivision-engine` 输出）
2. 确认 `NIKO_ENGINE_PLATFORM_URL` 地址正确、端口可达
3. 确认 `NIKO_ENGINE_NODE_ID` 和 `NIKO_ENGINE_AUTH_TOKEN` 正确
4. 在引擎端尝试 `curl http://平台地址/api/v1/edge-nodes/节点ID/heartbeat -X POST ...` 手动测试

### 算法包下发后状态长期为 pending

1. 检查引擎是否在线
2. 确认 MinIO 服务可访问
3. 检查心跳响应日志是否包含 pending_deployments
4. 查看引擎日志中 `AlgorithmDownloader` 和 `HeartbeatReporter` 的输出

### 节点显示版本不兼容

- 确认平台配置的 `engine.min_compatible_version` 不高于引擎版本
- 引擎版本通过 `InferenceEngine::Version()` 返回，当前为 `"1.0.0"`
- 升级引擎到兼容版本或调整平台最低版本配置

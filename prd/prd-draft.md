# AIVisionInference 产品需求文档 (Draft)

## 1. 文档概览
| 项目 | 内容 |
|---|---|
| 产品名称 | AIVisionInference 边缘视觉推理系统 |
| 版本 | V0.1 Draft |
| 目标硬件 | Rockchip RK3576/RK3588, Huawei Ascend |

## 2. 核心定义
- **控制面 (Go)**: 负责业务逻辑、API、任务编排、权限与系统配置。
- **数据面 (C++)**: 负责拉流、硬件解码 (MPP/DVPP)、NPU 推理、算法热加载。
- **ZLMediaKit**: 内置流媒体服务，处理 GB28181 接入与 Web 播放。
- **算法包**: 标准化交付格式，包含 `.so`、`algo_meta.yaml` 与 `label_map.json`。

## 3. 产品目标
- **高性能**: 支持单机 12+ 路 1080P 并发推理，P95 延迟 < 200ms。
- **标准化**: 统一算法接入规范，支持跨硬件部署。
- **自治性**: 深度集成 GB28181，支持完全离线运行与授权。

## 4. 功能架构

### 4.1 用户与权限 (RBAC)
- 多租户/多用户管理，基于角色的权限控制。
- 审计日志记录所有敏感操作（操作人、时间、对象、结果）。

### 4.2 设备管理
- 支持 RTSP、ONVIF 与 GB28181 设备接入。
- 支持设备分组与健康状态监控（心跳、拉流成功率）。

### 4.3 算法包管理
- 压缩包上传、版本管理、自检验证。
- **热更新**: 在不停止任务的情况下切换算法版本。

### 4.4 任务配置
- 视频流与算法的动态绑定。
- **规则引擎**: 针对 ROI (区域)、LINE (越界线) 的逻辑过滤。

### 4.5 智能记录
- 识别记录（所有人脸/人体/车辆抓拍）。
- 告警记录（触发业务规则的时间点）。
- 支持数据定期清理与分区存储。

## 5. 技术约束
- **零拷贝**: 数据面必须支持 dma_buf 跨进程流转。
- **隔离性**: 算法沙箱机制，防止第三方算法崩溃导致主程序退出。
- **国际化**: 前后端完全支持 i18n（中/繁/英）。

## 6. 路线图
- **V1.0 (MVP)**: RK3576 适配，12 路并发，基础任务编排，GB28181 接入。
- **V1.1**: Ascend 算力卡适配，ReID 跨镜追踪。
- **V2.0**: 算法市场对接，多机分布式编排。
